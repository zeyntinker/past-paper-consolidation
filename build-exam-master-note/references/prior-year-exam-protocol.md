# Prior-year exam-order protocol

## Source selection

Use only approved files from link 2 whose year equals `current year - 1` and whose exam scope matches link 1. Treat paired PDF and HWP/HWPX as one logical artifact.

Classify files as reconstruction/order sources, explanation sources, or combined sources. Preserve every selected variant.

## Order authority

Use the reconstruction file's visible problem order as the primary exam order. Do not reorder by lecture unit. When only an explanation file exists, use its order provisionally and mark the basis in the audit.

## Original preservation

For every sequence entry, include exact reconstructed problem and choices, exact original answer/explanation from every selected file, original images, and file/page/question ID/source order.

Do not silently choose one wording when reconstruction and explanation files differ.

## Supplement order

Supplement incomplete problems or explanations in this strict order:

1. Part 1 representative type: `[단권화 보충 · representative ID]`.
2. Verified authoritative external source: `[AI 외부 보충 · source]`.
3. `[출처 확인 필요]` when no trustworthy source exists.

Never relabel a supplement as original.

## Conflicts

- Content conflict: show all original variants side by side and add `[원문 간 불일치]`.
- Answer conflict: keep all answers and add a separately sourced assessment.
- Order conflict: do not decide silently; add `[순서 충돌 · 검수 필요]` and block completion.
- Missing image: include the source page and mark the exact missing relationship.

## Output contract

Follow the real exam sequence. Each entry contains the sequence number, all original problem variants, all original answer/explanation variants, separate Part 1 supplement, separate external supplement if required, and all conflicts/review states.

Part 2 may repeat Part 1; exam-order usability takes precedence over deduplication.
